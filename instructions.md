2. ASSIGNMENT DESCRIPTION
────────────────────────

Each group must select one or more Airbnb listings datasets from the link below:

- https://drive.google.com/drive/folders/1jbRd6nT0iDZvebEmuarsSezhKEQHPLUY

Four locations are available: California (USA), Belgium, Netherlands, and Rio de Janeiro (Brazil).

All datasets share the same variables:

• Property ID
• Property Name
• Host ID
• Host Name
• Neighbourhood (levels 1 and 2)
• Latitude
/ Longitude
• Property
/ Room Type
• Price — daily rent in local currency (note: Rio de Janeiro data is in Brazilian Reais)
• Minimum Nights allowed per stay
• Number of Reviews at the time of data collection
• Last Review — please ignore this variable
• Reviews per Month (average)
• Host Listings — total number of listings this host has on Airbnb
• Availability 365 — number of days the property was available on average over
the past year
