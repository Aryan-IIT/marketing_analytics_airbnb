How to read this site

Static
Q1 and Q2 are descriptive findings about the data. Nothing you enter changes them, so they ship as fixed figures with prose. They are measurements, and they would read the same for any host.
Live
Q3 and Q4 are scenario arithmetic on numbers from outside the listings file — property prices, minimum wages, nightly caps. Those become controls. Your settings follow you between pages and can be shared as a link, so you can hand someone the exact scenario you were looking at.
